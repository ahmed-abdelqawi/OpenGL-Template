# OpenGL Template for Windows

This repo is a template for graphics programming in OpenGL on windows. It's portable so all youe'll need to do is just clone it, run `build.bat` and let it do it's thing.

---

# How to run

```sh
git clone https://github.com/ahmed-abdelqawi/OpenGL-Template.git
cd OpenGL-Template
build.bat # [your compiler goes here (gcc or clang), ex: build.bat clang (will use clang++ to compile)]
```
